# How to Run the Road Risk Analyzer Website

See the root [RUN.md](../RUN.md) for full instructions.

### ⚡ Quick Start:
```powershell
# From this directory (road-risk-ml):
python frontend\api\app.py
```

Then open your browser to **[http://localhost:5050](http://localhost:5050)**.

- **No Node.js / `npm` needed.**
- The Flask server hosts both the ML REST API and the complete web frontend.
- Or double-click `..\run.bat` to launch automatically.
